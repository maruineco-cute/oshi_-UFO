# 推しがUFOに攫われるジェネレーター

推しの画像を選び、UFOの演出を楽しむブラウザー向けミニゲームです。

## ファイル

- `index.html` — アプリ本体。CSS・JavaScript・演出を含む単体ファイルです。
- `.gitignore` — OSが自動生成する不要ファイルを除外します。

## GitHub Pagesで公開する

1. GitHubで新しいリポジトリを作成します。
2. このフォルダー内の `index.html`、`README.md`、`.gitignore` をリポジトリの一番上（root）にアップロードします。
3. リポジトリの **Settings → Pages** を開きます。
4. **Build and deployment** で **Deploy from a branch** を選び、ブランチを `main`、フォルダーを `/(root)` にして **Save** を押します。
5. 公開が完了すると、同じページにサイトのURLが表示されます。

ビルド工程やサーバーは不要です。ローカルで確認する場合は `index.html` をブラウザーで開いてください。

## 動作について

- 効果音はWeb Audio APIで生成し、花びらではなく4色の星が降る演出を含みます。外部の音声素材・画像素材・CDNには依存しません。
- スマートフォンでは、最初のタップ後に音声が再生されます。音は画面上のボタンで切り替えられます。
- 選択した画像はブラウザー内で表示するだけで、サーバーへ送信しません。
- 身代わりコレクションの発見状況は、そのブラウザーのローカルストレージに保存されます。別の端末・ブラウザーとは共有されません。
